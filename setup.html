First-Time Setup

Select COM Ports

Choose two different COM ports — one for Aronium, one for this app. They will be linked as a virtual cable.

Virtual COM Driver

The app will install the bundled com0com driver and create the virtual cable automatically. No internet required.

COM20 ↔ COM21
What happens:
Aronium writes to COM20 → virtual cable → this app reads from COM21

Using COM20 ↔ COM21 — far from standard ports, zero conflict risk.
